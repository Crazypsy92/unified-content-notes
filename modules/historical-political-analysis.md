# 历史与政治分析

**模块类型：领域专项。** 适用于政治史、革命史、制度史、政治思想中的历史案例分析，以及把人物行动放入制度 / 群体关系中解释的作品。**先继承** [来源边界](../core/source-boundaries.md)、[质量检查](../core/quality-check.md)，并按文本结构加载 [观点分析](../core/argument-analysis.md) 和 / 或 [知识纪实分析](../core/knowledge-analysis.md)。本模块只补充历史政治分析焦点，不复制排版模板。

## 阅读时追踪什么

- **时间与转折**：建立有来源的最小时间线，区分作者的分期、外部编年事实和事后回看；解释某个日期为何在论证中构成转折，而不只罗列日期。
- **行动者与制度**：识别文本中的人物、政党、阶级 / 社会群体、议会、军队、行政机关、法律和媒体；记录各自的可用资源、目标、内部差异和约束。不能把群体名称当作其成员意图一致的证据。
- **利益、结盟与冲突**：追踪临时联盟如何形成、在何事上破裂，以及某项政治选择的得失。将组织行动、法律程序、选举规则、财政资源和强制能力放回具体历史条件。
- **因果链**：把“背景条件 → 触发事件 / 决策 → 机制 → 结果”分开。相关先后不自动等于因果；检查作者有没有给出中介机制、反例或替代解释。
- **政治表述与实际力量**：比较公开口号、宪法语言、组织代表关系和实际权力资源。话语会影响政治认同，但文本中的口号不能独自证明社会群体真实接受或统一行动。
- **作者的方法与位置**：识别作者是在场观察者、事后分析者还是档案研究者；考察材料来源、修辞、讽刺、分类和论证目的。把鲜明的政治立场作为分析对象，同时不因此自动抹去其材料价值。
- **群体中的人**：从有出处的制度和生活条件呈现劳动者、农民、被排除的选民、被镇压者及其他受影响群体；缺乏个案证据时写清集体层面的资料和未知，不虚构心理、经历或声音。

## 阅读单元如何划分

先读目录、序言和全书结构，再找叙事转折、概念转换、制度节点或作者明确的小结。可以一个章节为一单元，也可合并相邻章节，或在长章中按论证段落拆分。计划对每单元列明：事件范围、行动者 / 群体、利益与关系、作者处理的问题、该段在全书中的论证作用、待核事实。不能仅为“逐章摘要”而切段，也不提前写后续单元的总结。

## 史料与解释的标记

| 类别 | 记录方式 |
| --- | --- |
| 原作陈述 | 说明作者在本单元明说的内容；页码 / 章段只按实际阅读版本定位。 |
| 同时代材料 | 宪法、法律、议会记录、报刊、信函、档案等；记录日期、作者 / 机构和可见版本。 |
| 后出研究 | 标明作者、题名、年份及实际读到的范围；只读到摘要 / 出版社简介时不可称为通读。 |
| 互证事实 | 同时代独立来源或可信史学研究支持的内容；说明来源间的口径差异。 |
| 分析判断 | 从原文或材料推出的整理者解释，用“可理解为 / 本笔记判断”等标明；列出推理依据和限制。 |
| 未知 / 争议 | 记录现有材料无法判定的问题，不用平滑叙述隐去来源冲突。 |

## 独立评价与常见错误

检查作者的分类能否覆盖异质行动者、对代表关系的假设是否有材料、因果解释是否忽略制度或偶然因素、道德修辞是否替代了可核事实。允许提出替代解释，但需有证据；不要把现代政治概念直接套给十九世纪人物，不把政变结果写成早已注定，也不把行为动机从结果倒推。讽刺、夸张、比喻和人物评价要同时考虑其修辞作用与事实主张，不能当作中立档案。

## 最小验收

- 事件年代、制度规则和人物身份有来源；争议日期按版本注明。
- 时间线与作者的分析分期分开呈现；利益关系表不把身份直接等同于统一行动。
- 至少展开一条完整因果链并检查替代解释 / 反例。
- 外部材料明确标注为同时代来源、后出研究或编辑说明。
- 结论与已读单元范围相称，不提前代表全书，也不提供可替代原作的长篇转录。
