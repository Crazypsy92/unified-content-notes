## 人文思考引导模块

**父模块：** [通用叙事分析](../core/narrative-analysis.md)。
**共同约束：** 同时遵守 [来源真实性与材料边界](../core/source-boundaries.md)、[Markdown 默认规范](../core/markdown-style.md) 与 [通用质量检查](../core/quality-check.md)。

本模块是小说、电影、剧集、戏剧、短篇故事等文学与叙事作品的**可选思考层**。它不替代剧情梳理，也不把作品压缩成“人生道理”；它通过有证据的问题链，帮助读者从看懂故事，逐步走向理解人物、人性、社会、历史、伦理与艺术表达，并形成自己的判断。

## 适用与加载

- 用户明确提出“人文素养 / 人文思考 / 深度阅读 / 主题解读 / 带我思考 / 循序引导 / 联系现实”等要求时加载。
- 小说深读、电影主题分析或人物分析，如果目标包含理解人性、社会处境、价值冲突或艺术表达，可按需加载。
- 只要求剧情简介、情节复盘或人物名单时，默认只使用通用叙事分析；不要擅自增加一整套人文思考。
- 用户明确要求只改格式、保留原文时，不加载本模块，不添加问题、评论或现实启示。
- 用户只提供书名、片名、海报、链接、短评或二手解说时，先确认实际可读材料；不得把未观看 / 未阅读的原作说成已分析。
- 本模块可用于纪录片或真实事件材料，但要区分影像记录、当事人陈述、旁白、数据、情景重现和剪辑推断。

## 核心原则

1. **先看作品，再谈道理。** 每个重要判断都要回到具体情节、人物行动、对白、叙事安排或可观察的视听细节。
2. **理解不等于认同。** 理解人物处境不代表替其行为开脱；指出责任，也不抹去结构性限制。
3. **看见环境，也保留个人能动性。** 同时考虑个人选择、关系互动、社会条件和时代背景，不把人物写成环境的被动产物。
4. **允许多种解释。** 区分作品事实、叙述者 / 创作者表达、评论者观点和读者解释；存在分歧时保留分歧。
5. **不强行升华。** 不要求每部作品都提供正面启示，不把悲剧改写成励志故事，不把复杂人物简单分成好人和坏人。
6. **审美也是理解的一部分。** 不只问“讲了什么”，也问“作品如何讲述”，以及形式如何影响读者 / 观众的感受和判断。
7. **结论保持开放。** 可以形成暂时判断，也可以留下矛盾、疑问和无法轻易解决的地方。

## 循序渐进的思考路径

按作品和用户目标选择相关阶段，不必每次全部完成。由具体观察逐步走向解释，不要一开始就抛出抽象哲学结论。

### 第一步：从具体场景进入

先找到读者真正记住、困惑、反感或感动的场景。不要先问“作品告诉我们什么”。

- 哪个场景或人物选择让你停下来想了很久？具体发生了什么？
- 哪一句对白、一个动作、一个沉默或一个转折改变了你对人物的看法？
- 你的第一反应是什么？这种反应来自作品中的哪项细节？

**目标：** 建立共同的文本锚点，避免空谈主题。

### 第二步：理解人物的处境与选择

从人物当时拥有的信息、欲望、恐惧、责任、资源和可选路径出发。

- 人物当时最想得到什么，又最害怕失去什么？
- 他 / 她当时知道什么、不知道什么？有哪些现实选择？
- 如果换一个处境相近的人，是否也可能做出类似选择？
- 人物的言语、行动和真实需求之间是否存在矛盾？

**目标：** 从“这个人好 / 坏”推进到“这个人为什么这样行动，以及行动造成了什么后果”。心理动机只在作品有依据时写；推测必须标明。

### 第三步：看见关系与社会环境

把人物放回具体关系和时代条件中，辨认个人选择与外部结构如何共同作用。

- 冲突表面上是谁与谁的矛盾，深层是否还涉及家庭、阶层、财富、性别规范、劳动、权力或制度？
- 哪些人拥有更多选择权、话语权和资源？哪些人的声音没有被听见？
- 如果故事发生在另一个时代或社会环境，人物处境会有什么变化？
- 作品呈现的是个体遭遇，还是更普遍的社会处境？证据到哪里为止？

**目标：** 建立个人—关系—社会—时代的多层理解。涉及真实历史背景时，外部资料必须核验。

### 第四步：识别作品提出的人文问题

从作品实际呈现的冲突中选择少数相关维度，不要把所有主题都套上去：

- **尊严与价值：** 人是否被当作工具、标签或资源？谁有资格定义另一个人？
- **自由与责任：** 个人能够选择什么？选择需要承担什么代价？
- **欲望与自我认识：** 人追求的是某种生活、他人的认可，还是对自我的想象？
- **爱与家庭：** 关怀、占有、依赖、责任和控制如何区分？
- **阶层与机会：** 出身、财富、教育和社会关系如何影响人的可能性？
- **权力与不平等：** 谁制定规则，谁承担后果，谁被排除在叙述之外？
- **劳动与现代生活：** 工作如何塑造人的身份、时间和尊严？
- **战争、暴力与记忆：** 个体如何承受集体冲突，创伤如何被记住或遗忘？
- **衰老、死亡与失去：** 人如何面对有限性、告别和无法挽回的事？
- **技术与伦理：** 技术改变了什么，又把哪些责任交给人或机构？

**目标：** 把主题转化为可讨论的人类处境，而不是背诵主题标签。

### 第五步：尝试不同立场与反向解释

- 如果从另一个人物的立场看，这件事会如何被理解？
- 有没有一个情节不符合我们刚才的判断？
- 叙述者是否可靠？读者 / 观众知道的信息是否多于人物？
- 作品是否让某些人物缺席、沉默，或只通过他人描述出现？
- 还有没有一种同样能解释现有证据的读法？

**目标：** 训练换位理解和判断边界，而不是追求唯一标准答案。

### 第六步：理解艺术形式如何表达意义

根据媒介选择证据。不要把小说分析方法机械套到电影，也不要仅凭剧情简介虚构视听细节。

**小说 / 文学作品：**
- 叙述者与视角：谁在讲述，谁的内心被看见，谁被遮蔽？
- 叙事时间：倒叙、插叙、重复、留白和节奏如何改变理解？
- 语言与意象：反复出现的物件、地点、动作、称呼和比喻有什么作用？
- 结构与反讽：开头和结尾如何呼应？读者是否被引导先相信某种判断？

**电影 / 影视作品：**
- 镜头景别、机位、运动和构图：观众被安排在什么位置观看人物？
- 光线、色彩、场景调度和道具：空间如何表现关系、权力或情绪？
- 剪辑、节奏、转场和视点：哪些信息被并置、延迟或省略？
- 声音、音乐与沉默：情绪如何建立，画面与声音是否形成反差？
- 演员表演与身体动作：人物没有说出口的内容如何呈现？

**纪录片 / 真实事件影像：**
- 镜头记录、采访证言、旁白、数据、历史影像和情景重现分别提供什么证据？
- 剪辑顺序是否影响因果印象？有哪些当事人或材料没有出现？

**目标：** 解释形式如何影响意义。只有用户提供画面 / 视频，或当前确实可访问作品时，才能对具体镜头和声音作事实描述；只有字幕或剧情梗概时，只能分析文字中可见的信息。

### 第七步：联系当下，但不强迫自我暴露

- 作品中的处境在今天是否仍然存在？相同点和不同点分别是什么？
- 今天的制度、技术、观念或生活条件改变了什么，又留下了什么？
- 这个故事让你重新审视了哪一种习以为常的判断？
- 你可以理解人物，但仍然无法接受他的哪种行为？为什么？

**目标：** 把阅读转化为现实理解，不要求用户分享私人经历，也不把作品简单当成现实案例或道德教材。

### 第八步：形成暂时判断，并保留问题

最终整理可采用以下思路，而不是硬写成“人生启示”：

- **作品事实：** 哪些具体情节 / 形式细节是判断依据？
- **一种解释：** 它可能反映了什么人性、关系或社会问题？
- **另一种解释：** 是否存在不同立场或反例？
- **暂时判断：** 目前更认可哪种理解，理由是什么？
- **仍未解决的问题：** 哪些矛盾值得继续思考？

不要求每部作品都有明确答案。能够准确描述矛盾、理解不同立场并说明判断依据，本身就是有效的阅读成果。

## 互动引导协议

当用户说“带我思考”“一步步引导我”“不要直接给答案”时，采用对话式引导，而不是一次性输出一整套问卷：

1. 先确认作品范围和当前讨论的场景 / 人物；材料不清楚时只问一个必要问题。
2. 每轮只提出 **一个核心问题**，必要时附一个具体观察提示；不连续抛出多个互不相关的问题。
3. 等用户回答后，先回应其观点中有依据的部分，再指出可能遗漏的视角、证据或反例，然后进入下一阶段。
4. 不急着纠正用户，也不把自己的解释包装成标准答案；可提供两三种可能读法，让用户比较。
5. 用户卡住时，给出具体情节线索或两个不同方向作为脚手架，但仍把判断权留给用户。
6. 用户要求完整分析或整理成笔记时，可以一次呈现完整路径；不要为了互动而故意拆成多轮。
7. 不设计考试式测验，不使用连续选择题，不要求用户必须回答私人经历。

**推荐节奏：** 具体场景 → 用户初步反应 → 人物处境 → 关系 / 社会视角 → 比较不同解释 → 暂时判断。根据回答灵活前进；某一步已自然解决，就不必机械重复。

## 静态笔记的呈现方式

用户要求整理成完整笔记时，可在剧情梳理和作品分析之后加入“循序思考”或“延伸思考”部分：

- 选择 3—6 个最有价值的问题，按由具体到抽象、由文本到现实的顺序排列。
- 每个问题附近提供必要的情节锚点和思考方向；不要只堆问题，也不要替读者写好唯一答案。
- 用户希望获得参考答案时，使用“可能的理解 / 一种读法”，并列出支持依据与解释边界。
- 保留“我暂时还不能确定”的空间；不强求正能量、成功学结论或统一的道德评价。
- 沿用本 Skill 既有的 Markdown / Obsidian 标题和 Callout 规范，不另造视觉模板。

## 交付前检查

- [ ] 思考从具体场景、人物行动、对白或可观察的艺术细节出发，而不是先贴主题标签。
- [ ] 区分作品事实、人物自述、叙述者表达、创作者意图、外部评论和整理者解释。
- [ ] 理解人物处境，同时保留对其行为后果与责任的判断。
- [ ] 同时考虑个人选择、关系互动和社会 / 时代条件，避免单因解释。
- [ ] 提供不同立场或反向证据，而不是只寻找支持第一印象的材料。
- [ ] 根据媒介分析文学语言 / 叙事结构或电影视听语言，没有把两种媒介混为一谈。
- [ ] 避免强行输出“人生启示”、简单道德评判或未经证实的作者意图。
- [ ] 互动引导每轮只问一个核心问题，并根据用户回答推进。
- [ ] 只有字幕、梗概或片段时，明确限制对镜头、声音、全文和结局的判断。
