# 跨文体精读路由

**模块类型：路由模块。** 本模块只选择阅读焦点和必要的既有模块，不建立统一模板。先识别用户要做什么（总结、讲解或只改格式），再识别材料的结构，最后选择以下文体 / 学科视角。未明确指定时按材料本身路由，不为分类而打断用户。

## 五类文体

| 文体视角 | 识别线索与阅读重点 | 复用模块 |
| --- | --- | --- |
| **历史与政治分析** | 历史脉络、人物 / 制度、阶级或社会群体、资源与利益、联盟 / 冲突、政治力量、事件因果；检查作者如何用历史材料支持解释。阅读单元按实际论证转折与时间段划分，不默认“一章一摘要”。 | [历史政治专项](historical-political-analysis.md) + 按文本结构加载 [观点分析](../core/argument-analysis.md) 和 / 或 [知识纪实分析](../core/knowledge-analysis.md) |
| **调查研究与报告** | 谁被调查、调查对象和抽样范围、时间 / 地点 / 方法、材料类别、记录者位置、事实与推断 / 建议的界限；看证据链是否覆盖结论。 | [知识纪实分析](../core/knowledge-analysis.md)；方法本身是重点时再加载 [方法笔记](../core/method-notes.md) |
| **理论与哲学** | 核心概念的定义和语境、前提、概念之间关系、推理步骤、论证对象、反例和适用范围；追踪同一术语在书中是否发生变化。 | [观点分析](../core/argument-analysis.md)；材料是理论史或知识论述时按需加载 [知识纪实分析](../core/knowledge-analysis.md) |
| **演讲与思想随笔** | 写作 / 发言场合、听众、要处理的问题、主要命题、观点冲突、修辞和价值判断；区分文本论证、现场回应、后续传播与事后解释。 | [观点分析](../core/argument-analysis.md) + 按实际结构加载 [叙事分析](../core/narrative-analysis.md) 或 [知识纪实分析](../core/knowledge-analysis.md) |
| **小说与文学** | 情节和叙事顺序、人物处境 / 行动 / 后果、视角、关系、主题、语言与形式；包括完整中短篇及合订本的逐篇精读 / 文风返修，分清人物、叙述者、作者、读者解释。 | [叙事分析](../core/narrative-analysis.md) + [小说深读](novel-analysis.md)（读者视角与高保真返修）；人文思考按需加载 [人文引导](humanistic-reflection.md) |

## 所有路线共享的工作流

1. **资料边界**：确认当前可读的是哪个版本 / 译本、完整文本还是选段，记录缺页、缺章和不可访问材料。
2. **原文定位**：先核目录、前言、章节层级与附录；引用定位到章 / 节 / 段或文件内可验证锚点。只有确知版次和页码时才写页码。
3. **证据管理**：把原文主张、原始文献、后出史料、学术研究、编者说明和整理者推断分层；记录来源能够证明什么、不能证明什么。
4. **独立评价**：检查论证是否成立、反例与遗漏、作者立场和材料限制；不以赞同或反对替代文本分析。
5. **知识关联**：只建立真实存在或本轮一并创建的 Obsidian 双链；链接用于回查相关概念 / 人物 / 作品，不用空链制造完成感。
6. **分段接力**：长篇作品按实际论证单元推进；每轮只完成进度文件指定的一个单元，更新本轮完成范围、未解问题和下一单元。

## 路由边界

- 文体视角不等于文本结构：历史书中的一章可能以论证为主，调查报告可能包含叙事，演讲也可能以案例推进。按实际结构组合模块。
- 专项继承通用来源边界、版权规则、Markdown / Obsidian 排版和质量检查；不得另造重复模板。
- 用户给定的篇目 / 阅读单元优先；没有用户指定时，可依据目录和论证结构制定计划，并说明分段依据。
- 材料不足时保留问题并推进独立可完成的部分；不因计划存在而补造史实、页码或作者意图。
