## 来源真实性与材料边界

本文件是所有任务的通用底线。整理稿必须忠实于当前实际可读的素材，不能把推断伪装成来源事实。

## 1. 先确认素材范围

开始前在内部确认：

- 标题、作者 / 来源、作品或期数（仅在已知时记录）。
- 输入是完整材料还是片段；是否缺页、缺章节、缺结尾。
- 当前实际拥有的是原文、字幕、ASR 转写、OCR、截图、图表，还是仅有标题 / 链接。
- 一份材料中是否混有多篇内容、作者补充、评论、用户个人感悟或广告。

只有标题或链接时，不得声称已看过视频、读完整本书或看完整部电影。只能基于当前可访问内容整理，并明确范围。

## 2. 区分信息来源

需要区分：

1. 可直接观察或由材料明确记载的事实；
2. 创作者 / 讲者的观点与判断；
3. 被引用者、受访者或评论者的说法；
4. 用户自己的批注、感悟和复盘；
5. 基于材料作出的推断；
6. 外部资料提供的补充或核验。

不要把评论当成主讲者观点，不要把个人经历写成普遍规律，不要把计划写成已完成，也不要把相关性直接写成因果关系。

## 3. ASR、OCR 与多媒体边界

- 只有字幕或转写时，只能总结文字呈现的信息；不能描述未提供的镜头、表情、屏幕图表或动作。
- 图片 / 图卡应按实际页序阅读；只收到部分图片时，明确缺失范围，不根据封面或标题补写后续。
- ASR / OCR 的明显错码只有在修正高度确定时才可规范；人名、数值、专业术语和作品设定不确定时保留原文并标记“转录待核”。
- 若用户明确要求 ASR 口播校订，必须区分“原始 ASR 备份”和“校订阅读版”：允许补标点、按语义断句分段，只修正高置信度错词；无法确认的片段用“听辨存疑”标记。
- 只有 ASR 文本、没有音频时，必须注明“基于 ASR 文本校订，未核听音频”；不得声称完成音频核对。人名、数字、单位、专有名词和残缺结尾不得靠标题或相似话题猜补。
- 校订阅读版不是逐字原文；移除高亮后应还原校订阅读版本身，原始 ASR 必须另行保留。
- “只改格式”模式不自动校正错别字、ASR 错误或事实错误。

## 4. 外部知识与核验

- 用户没有要求外查时，不要把外部知识无声混入原文摘要。
- 用户要求核验 / 拓展时，将外部资料单独标识，并区分来源、原文主张和新增解释。
- 没有可靠证据时说明不确定性，不以常识、模型记忆或流畅表达填补缺失证据。
- 不承诺 Skill 本身具备下载、转录、OCR、登录访问或绕过平台限制的能力；这些取决于当前助手实际可用的工具和用户提供的素材。

## 5. 版权与替代性

对电影、小说、书籍、视频等受版权保护作品，提供原创摘要、评论和分析；不要在用户未提供完整文本且无授权时重建可替代原作的大段内容。用户提供的文本也应尊重其来源和使用边界。
