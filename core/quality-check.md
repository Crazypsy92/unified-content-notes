## 通用质量检查

交付前在内部完成以下检查；除非用户要求，不展示冗长审计过程。

## 四道检查

1. **任务一致性**：是否正确执行总结、讲解或只改格式？是否擅自增加用户没要求的版本、评价或外部知识？
2. **信息覆盖**：独立论点、必要论据、关键案例 / 对话、数字、比喻、反例、转折、限制条件和结局是否保留？
3. **来源忠实**：是否区分事实、观点、转述、推断和外部补充？是否把并列写成因果、把计划写成结果，或补造心理、动作、台词和场景？
4. **阅读质量**：标题、段落、表格和小标题是否克制清楚？是否存在过度压缩、重复解释、第三人称旁白或格式错误？

## 高保真信息台账

对中长材料，在内部快速记录：

- 中心主张与每个独立分论点；
- 每个论点的前提、理由、证据、推理和适用边界；
- 核心案例的背景、起因、行为、关键对话、回应和结果；
- 重要数字、时间、对照、比喻、反例、转折和情绪变化；
- 原始叙述视角、用户个人补充及其来源边界。

信息台账是防止遗漏的检查工具，不是要求输出一份额外表格。

## 根据用户反馈修正

| 用户反馈 | 修正方式 |
| --- | --- |
| 内容损失、案例 / 论据遗漏 | 回到原始素材逐项找回独立信息单元，不靠空泛扩写增加字数 |
| 太长、重复、不美观 | 合并重复解释、删空泛过渡、缩窄表格和减少无意义标题；不删除唯一论据 |
| 旁白太多 | 去掉整理者叙述，直接写观点、事实和推理；来源只在必要位置归属 |
| 情绪不足、像报告 | 恢复原有视角、语气、反问、比喻和关键表达，不额外煽情 |
| 小标题太多 | 合并同一论证任务的小节，保留真正有助理解的层级 |
| 压缩过度 | 对照原文恢复被删掉的证据、案例事实链和推理环节 |
| 要沿用之前的风格 | 回到本 Skill 的高保真默认规范，不沿用未经确认的临时试验格式 |

## 模式专属检查

- **观点分析**：论点与依据真实对应；案例在正文中展开；结论边界清楚。
- **叙事分析**：人物、事件、时间线和结局没有串线；未交代的内容保持未交代。
- **知识纪实**：观察、证言、专家意见、假设、计划和已验证事实没有混淆。
- **对话分析**：说话人和轮次准确；原话、转述和建议话术有清楚区分。
- **方法笔记**：步骤顺序、参数、前置条件、输入输出和限制没有丢失。
- **只改格式**：对照原文确认非排版字符未改变；没有总结、润色、校对或重排事件。
