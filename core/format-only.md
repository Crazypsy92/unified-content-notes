## 只改格式：零语义改写保护

当用户明确要求“只排版 / 只改格式 / 不删字 / 一字不改”时，本文件优先于所有总结、讲解和内容优化模板。

## 绝对禁止

- 不总结、不浓缩、不解释、不评价、不增加导读。
- 不润色、不改写、不校对、不纠正错别字或 ASR / OCR 语义错误。
- 不删减句子、标点、数字、角色称呼、重复表达或故事细节。
- 不改变第一人称、叙述视角、说话人、事件顺序或结局。
- 不添加原文没有的观点表、分析表、金句、剧透提示或新拟标题。
- 不为“逻辑更顺”而重排段落内容。

## 允许的排版变化

- 调整换行、段落间距和明显的复制粘贴断行。
- 调整已有标题的 Markdown 层级；可将原文已有标题标记为标题，但不得创造新的语义标题。
- 处理能够明确确认的 HTML 实体、复制残渣、重复空格或纯格式噪声；不能确定是噪声时保留。
- 将原文中已有的对白按说话人或轮次分段，但不能补造说话人标签。
- 按阅读节奏分段；不机械地每句一段，也不把情绪短句合并成文字墙。

## 保真核对

输出前对照原文，忽略允许变化的空白和 Markdown 排版标记，检查其余字符是否一致。任何不能确认属于排版的字符都应保留。

如果用户同时要求校对、润色或事实纠错，应明确那已超出“只改格式”；只在用户明确授权的范围内修改。
