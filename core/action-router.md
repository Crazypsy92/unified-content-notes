## 处理动作路由

处理动作与内容结构是两个独立维度：动作决定“要对素材做什么”，结构决定“素材应该怎样组织”。先判断动作，再选择内容模块。

## 三个核心动作

| 动作 | 常见表达 | 允许的变化 | 默认交付 |
| --- | --- | --- | --- |
| **总结 / 高保真浓缩** (summarize) | 总结、整理、做笔记、概括、提炼观点、梳理剧情、复盘 | 删除口头重复和无新增信息的内容；重组结构；保留独立观点、证据、案例和关键情节 | 适配素材结构的 Markdown 笔记 |
| **讲解 / 深度分析** (explain) | 解释为什么、讲透、分析逻辑、解读人物 / 作品 / 原理、看不懂 | 在来源事实基础上解释概念、前提、因果、动机和边界；新增分析必须可辨 | 来源脉络 + 有依据的解释 |
| **只改格式** (format-only) | 只排版、仅改格式、不删字、一字不改、保留原文 | 仅调整版式；不总结、不润色、不校对、不改写、不改变事件顺序 | 原文 Markdown 阅读排版稿 |

## 判断规则

1. 用户明确指定动作时，严格按指定动作执行。
2. 用户说“整理 / 做笔记 / 概括 / 精简”但未说明其他要求时，默认总结。
3. 用户问“为什么 / 怎么理解 / 讲透 / 解读”时，默认讲解。
4. 用户说“只排版 / 不删字 / 不改原文”时，进入 format-only 保护模式。
5. 用户同时要求总结和讲解时，可在同一成品中先整理来源内容、再单独标注解释；只有用户要求多版本时才生成多份。
6. 用户同时提出“只改格式”和“润色 / 总结”等冲突要求时，指出冲突并优先遵守更明确的限制；若用户明确授权某一类文字修改，则只修改授权范围。
7. 不因素材是电影就自动分析主题，不因内容涉及情感就自动做心理解释，也不因材料有故事就把它改成故事会。

## 高保真默认

总结不是极限压缩。没有固定字数或压缩比例，篇幅由素材的信息密度决定。相同意思的重复表达可以合并；不同案例、独立论点、关键对话、数字、反例和限制条件不能只因结论相似而删除。

讲解必须把“来源实际提供的内容”和“新增解释”区分开。不能为了让论证顺畅而补造前提、证据或因果关系。

只改格式的详细保护要求见 [format-only](format-only.md)。
