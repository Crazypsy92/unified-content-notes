## 默认 Markdown 与阅读规范

这些是默认值，用户明确指定其他格式时可以覆盖；但不得破坏内容真实性或 format-only 的零语义改写要求。

## 标题与段落

1. 保留用户提供的原始标题及其标点，不擅自改题。
2. 成品最高标题级别为二级：## 原标题；正文主题使用 ###，必要时使用 ####，不使用一级标题。
3. 中文自然段首行缩进两个全角空格：　　。标题、表格、列表和引用块不缩进。
4. 段落围绕完整意思组织：避免一句一段，也避免连续的大段文字墙。
5. 小标题表达真实逻辑层次；合并相近小节，不为凑模板增加“文章思想 / 正文浓缩 / 最终落点 / 金句摘录”等重复标题。

## 表格、强调与链接

- 观点分析长文或多案例材料通常适合紧凑的论点 / 依据 / 推理 / 边界表；短故事、纯对话、短文案和只改格式不强制使用表格。
- 表格通常不超过四列，单元格只放导航信息，不塞入整段正文。表格不能替代案例正文。
- 加粗只标记少量关键判断，不整段加粗；引用块主要用于原始对白或确有必要突出的原句。
- 不使用 HTML 表格、内联样式或装饰性空白堆砌版面。
- 只有实际创建文件时才提供下载链接；文件名和代码标识符默认使用英文，正文语言遵循用户要求。

## 内容呈现

- 默认输出中文；用户要求其他语言时按要求切换。
- 来源在标题下标注一次即可；不明来源不猜测。
- 个人感悟、创作者观点、引用内容和外部补充应清楚区分。
- 只输出用户需要的成品，不默认展示内部信息台账或冗长检查清单。
