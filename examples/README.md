# Original demonstration examples

These miniature source/output pairs were created specifically for this repository. They are examples of three operations, **not** rigid templates for arbitrary content. They contain no copied passages from uploaded transcripts or other creators' published works.

- `argument-input.md` / `argument-summary.md`: compact argument overview plus reasoning.
- `narrative-input.md` / `narrative-summary.md`: story progression and reveal without an invented lesson.
- `format-input.md` / `format-only.md`: formatting-only sample verified for character preservation.
