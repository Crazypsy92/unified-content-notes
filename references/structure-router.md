## 内容结构路由

先锁定处理动作：总结 / 高保真浓缩、讲解 / 深度分析、只改格式。再识别内容模式。动作与内容模式是两个独立维度；用户可以指定“文案 + 观点分析型”等组合，也可以让 Skill 自动判断。

| 内容模式 | 识别线索 | 总结时的组织方式 | 不应做的事 |
| --- | --- | --- | --- |
| 观点分析型 | 主张、原因、论据、类比、反问、结论 | 原标题 + 紧凑论点/依据/推理表 + 高保真正文 + 必要边界 + 个人感悟（如有） | 只剩观点清单；把案例只放表格；第三人称旁白；过度压缩 |
| 故事 / 经历型 | 人物、处境、目标、冲突、行动、结果 | 按事件顺序保留人物关系、动作、关键对话、情绪变化和结局 | 强行套论点表；把故事缩成鸡汤结论；补写未提供的情节 |
| 情侣对话型 | 多轮对话、误会、冲突、回应、修复 | 分角色、按轮次排版；必要时分析需求和冲突 | 把原话改成小说对白；编造对方心理；未经要求擅自润色 |
| 短文案 / 金句型 | 一句话观点、短摘录、标题、语录合集 | 尽量保留原句，按主题归类，来源信息一次 | 为了显得完整而扩写成文章；伪造出处 |
| 方法 / 经验型 | 建议、原则、步骤、实践经验 | 问题/目标 → 原则 → 步骤 → 示例 → 条件与边界 | 丢失步骤顺序、参数、关键例子或适用条件 |
| 个人感悟型 | 第一人称、主观体验、犹豫、复盘 | 保留第一人称和原有情绪，按真实思考顺序整理 | 改成第三人称大道理；把矛盾和不确定强行抹平 |
| 作品 / 人物解读型 | 小说、电影、纪录片、人物经历 | 作品事实与人物行为 → 变化过程 → 有证据的解释 | 用模型印象替代提供的材料；编造台词或情节 |
| 图文 / 多页卡片型 | 多张截图、轮播图、卡片顺序 | 保留页序、图中文字、数字和页间关系 | 只总结封面；漏掉后续页关键条件 |
| 混合型 | 同时包含观点、案例、对话、方法、个人感悟 | 分段识别局部结构，必要时组合多种组织方式 | 强行把所有部分改成同一种模板 |

## 观点分析型：原有高保真架构

观点分析型适用于情感关系、沟通、吸引力、择偶、婚姻和个人认知等以论证为主的材料。

默认顺序：
1. 保留原始标题。
2. 标题下标注一次来源；不明来源不猜测。
3. 放一张紧凑总览表，通常四列：核心论点、原文依据/案例、推理关系、结论/适用边界。
4. 按原材料的思想推进顺序写正文。保留必要逻辑小标题，但不强制添加重复模板标题。
5. 有用户自己的感想、评论或复盘时，放在文章末尾并与来源观点区分。
6. 仅在确有必要时添加观点边界说明或外部核验。

### 论据和案例

写作前在内部建立信息台账，记录独立论点、理由、关键案例、关键对话、数字、比喻、转折和限制条件。表格负责导航，正文负责把论证讲完整。

核心案例在正文中保留必要的背景、起因、行为、对话、回应和结果，并解释它如何支撑观点。不同案例即使结论相似，只要证据不同，也不能压成一个泛泛例子。案例可以简洁，但必须让读者知道具体发生了什么；不得补造原文没有的细节。

### 口吻与排版

- 避免“作者认为 / 原文指出 / 讲者举例说明 / 这篇文章讲了”等第三方旁白，直接陈述观点和事件。
- 保留原材料的人称和情绪：第一人称经历保留“我”，直接对听众说话可保留“你”，故事按人物叙述。不要机械统一人称。
- 保留反问、比喻、对照和有辨识度的表达，不靠额外煽情形容词补情绪。
- 没有固定字数或压缩比例；删重复，不删论证所需的信息。
- 小标题按真实逻辑设置，相近主题合并；不一句一段，也不形成大段文字墙。
- 表格不宜过宽，加粗克制；不要让表格和正文重复堆叠。

## 篇幅判断：简洁但不丢信息

- 短材料：保留完整意思，几段即可，不强制加表格。
- 中等材料：总览表 + 连贯正文，展开关键案例。
- 长材料：按主要论点或事件阶段分节，保留独立证据；内容密集时可以写长。
- 不设固定压缩比例或字数上限。压缩掉重复内容后，仍必须能从正文还原关键论证。

## 讲解与总结的区别

- 总结：忠实浓缩原文观点、证据、案例和结构，不无声加入外部解释。
- 讲解：在原文基础上解释概念、前提、因果和适用边界；新增分析必须与原始内容区分。
- 只改格式：只调整排版，禁止总结、解释、润色或添加分析。
