## 格式与质量门槛

### 统一 Markdown 输出

- **原标题原样保留**：`## 原标题`，小节 `###`，必要时 `####`；不使用一级 `#`。
- 中文自然段首行两个全角空格 `　　`；段间留一个空行；Markdown 标题、表格、无序/有序列表、引用不加缩进，以免渲染失效。
- 不使用 HTML `<br>`、强制空行或整段加粗。表格列不要太多；正文不塞进一个超长单元格。
- 输出中文内容，文件名/目录英文；如果用户本来给了标题，正文不重命名，文件名可以英文编号以保障检索；在 index 中列原标题与文件名。
- 用户提供的个人感悟单独保留为“个人感悟”，除非用户说要融合；不可放进原始来源观点里。

### 观点分析型正文：分析文章，不写成故事会

适用于情感观点口播、亲密关系分析、沟通、择偶、婚姻等以论证为主、包含一个或多个案例的材料。

**推荐版式：**

1. `## 原始标题`，必要时注明来源。
2. `### 文章思想`：直接写核心问题和主旨，不用第三方介绍口吻。
3. `### 论点与论据分析`：用短表格对应核心论点、原文案例/论据、推理关系和结论落点。
4. `### 正文分析`：按逻辑顺序分为若干小节；小标题表达分析判断，不写成文学化场景标题。
5. 核心案例在正文单独展开，保留情境、事实、关键对话、回应/结果，并解释其论证作用。
6. `### 最终落点`：总结真正成立的结论及必要边界。

**正文视觉要求：**

- 正文以连续、自然的分析段落为主，每段围绕一个论证任务；不一句一段，也不堆成大段文字墙。
- 案例细节为论证服务。不要擅自添加环境、神态、心理独白、动作或戏剧转折，不要把观点文章写成轻小说、故事会或短剧脚本。
- 小标题应体现观点或推理关系，例如“临时改变安排时，提前说明仍然重要”，避免“那个夜晚，她终于明白……”一类故事化标题。
- 多个案例分别说明，不合并人物经历；案例后要解释它支持什么、不能证明什么。
- 表格是分析导航，正文必须进一步解释，不能用表格替代文章。
- 详细规范见 [argument-analysis-layout.md](argument-analysis-layout.md)。

### 情侣对话的排版

- 原始对话使用角色标签和 Markdown 引用块，让轮次清晰；不要把普通对话全部改写成小说对白。
- 对话后紧接“对话分析”，说明可观察到的表达重点、未回应的问题及可能影响。
- 多轮对话需要比较时，可用“对话表现 / 可确认的信息 / 可能影响”小表格。
- 新拟话术必须标记为“调整示例”，不得伪装成原话；推测对方意图时使用谨慎措辞。

### 四道审核

1. **任务一致性**：是否真的按请求“总结/讲解/只排版”？是否因平台或题材擅自切换？
2. **来源覆盖**：是否保留独立论点、关键动作和对白、数字、时序、反例、隐喻、结局？核心案例是否在正文展开，而非只在表格中出现？若源材料不完整，是否说明？
3. **证据可靠性**：是否把宣传话术/来源推测/个人观察写成事实？是否混合主讲者与评论？是否杜撰影视台词、研究结论、画面、人物心理或故事细节？
4. **阅读流畅性**：小节逻辑是否能顺着看？是否有机械分点和重复叙述？观点分析是否保持分析文章形态，而非故事会？对话是否易读？Markdown 表格是否正常、最大标题是否二级？

### 只改格式专用的保真核对

- 比较原文清除**明确可确认复制噪声**前后的非排版字符序列。
- 允许改变：普通/全角空格、换行、段落间空行、Markdown 标题标记、仅用于排版的列表标记、确定是转义伪影的 `&#x20;` 和多余断行 `\\`。
- **不允许改变**：具体词句、标点、英文与数字、角色代称、原始引号内说话内容、事件先后、章节标题含义、故事结尾；不擅自把“口语”润色成“书面语”。
- 若原文本身语病严重，可附一句“原文保留；如需可另做校对”，不要在纯排版输出中擅自修改。
- 重要短句可单独成段（悬念、反转、对白），其他叙述保持适中的自然段，不强制每句话换行。
- 若输入包含多个故事，按确实可辨的边界拆分；缺少标题者保持无标题，`index.md` 仅使用编号导航，不把编号当故事标题。

### 可解释的不足，而不是假装完整

- “根据已提供的第 1—2 章整理，未含后续结局。”
- “该笔记仅提供视频转写，未见画面中的表格/动作细节。”
- “此段有关激素的说法属于来源原文描述，未做科学来源核验。”
- “已按你的要求保留原标题并调整排版；没有更正原文错别字。”

### 内容检查清单（内部，不强制用户看）

```
[ ] 3 种动作之一判定正确
[ ] 标题保留与素材完整性已核对
[ ] 原文各独立论点/事件/数字映射到成稿
[ ] 核心案例在正文展开，而不只是出现在总览表
[ ] 观点分析正文使用分析型标题和自然段，没有小说化补写
[ ] 情侣对话分角色清晰排版，原话与改写区分
[ ] 案例结构（背景-行为-回应-结果-论证作用）保留
[ ] 没有跨作者/跨时间/跨媒介混淆
[ ] 任何讲解补充已和原文内容区分
[ ] format-only 模式未更改任何非格式字符
[ ] ## 最高；中文自然段两全角缩进
```
