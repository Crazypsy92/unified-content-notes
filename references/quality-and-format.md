## 格式与质量门槛

### 统一 Markdown 输出

- **原标题原样保留**：`## 原标题`，小节 `###`，必要时 `####`；不使用一级 `#`。
- 中文自然段首行两个全角空格 `　　`；段间留一个空行；Markdown 标题、表格、无序/有序列表、引用不加缩进，以免渲染失效。
- 不使用 HTML `<br>`、强制空行或整段加粗。表格列不要太多；正文不塞进一个超长单元格。
- 输出中文内容，文件名/目录英文；如果用户本来给了标题，正文不重命名，文件名可以英文编号以保障检索；在 index 中列原标题与文件名。
- 用户提供的个人感悟单独保留为“个人感悟”，除非用户说要融合；不可放进原作者观点里。

### 四道审核

1. **任务一致性**：是否真的按请求“总结/讲解/只排版”？是否因平台或题材擅自切换？
2. **来源覆盖**：是否保留独立论点、关键动作和对白、数字、时序、反例、隐喻、结局？若源材料不完整，是否说明？
3. **证据可靠性**：是否把宣传话术/作者推测/个人观察写成事实？是否混合主讲者与评论？是否杜撰影视台词、研究结论、画面？
4. **阅读流畅性**：小节逻辑是否能顺着看？是否有机械分点和重复叙述？是否对应该有的情绪变化作了自然留白？Markdown 表格是否正常、最大标题是否二级？

### 只改格式专用的保真核对

- 比较原文清除**明确可确认复制噪声**前后的非排版字符序列。
- 允许改变：普通/全角空格、换行、段落间空行、Markdown 标题标记、仅用于排版的列表标记、确定是转义伪影的 `&#x20;` 和多余断行 `\`。
- **不允许改变**：具体词句、标点、英文与数字、角色代称、原始引号内说话内容、事件先后、章节标题含义、故事结尾；不擅自把“口语”润色成“书面语”。
- 若原文本身语病严重，可附一句“原文保留；如需可另做校对”，不要在纯排版输出中擅自修改。
- 重要短句可单独成段（悬念、反转、对白），其他叙述保持适中的自然段，不强制每句话换行。
- 若输入包含多个故事，按确实可辨的边界拆分；缺少标题者保持无标题，`index.md` 仅使用编号导航，不把编号当故事标题。

### 可解释的不足，而不是假装完整

- “根据已提供的第 1—2 章整理，未含后续结局。”
- “该笔记仅提供视频转写，未见画面中的表格/动作细节。”
- “此段有关激素的说法属于视频原文描述，未做科学来源核验。”
- “已按你的要求保留原标题并调整排版；没有更正原文错别字。”

### 内容检查清单（内部，不强制用户看）

```
[ ] 3 种动作之一判定正确
[ ] 标题保留与素材完整性已核对
[ ] 原文各独立论点/事件/数字映射到成稿
[ ] 案例结构（背景-动作-回应-结果）保留
[ ] 没有跨作者/跨时间/跨媒介混淆
[ ] 任何讲解补充已和原文内容区分
[ ] 格式-only 模式未更改任何非格式字符
[ ] ## 最高；中文自然段两全角缩进
```


## 情感观点分析型：案例与正文排版质量门槛

- [ ] 正文采用分析文章结构，而不是故事会、轻小说或影视化叙事。
- [ ] 文章思想与论点论据表清楚，主要论点有对应案例和推理。
- [ ] 核心案例在正文逐个展开必要事实，不只出现在表格中。
- [ ] 案例保留必要背景、行为、关键对话和结果；没有添加原文不存在的环境、表情、心理独白或戏剧化情节。
- [ ] 案例展开后有紧贴证据的分析，解释它支持什么、不能证明什么。
- [ ] 情侣对话用清楚的说话人标签和 Markdown 引用块呈现；不擅自补姓名；对话后有分析。
- [ ] 正文按逻辑分节，段落完整；没有一句一段、标题过碎或列表化替代论证。
- [ ] 表格简洁可读，不把长故事或整段对话塞入单元格。
- [ ] 加粗、引用块和小标题用于帮助阅读，不作装饰堆叠。

具体写作示例与规则见 [relationship-analysis.md](relationship-analysis.md)。
