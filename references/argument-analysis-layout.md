## 观点分析型：高保真整理规范

本规范适用于观点型口播、情感关系文案、亲密关系认知、沟通、择偶、婚姻、个人成长，以及包含多个案例和对话的论证材料。

目标是把原材料整理成**可独立阅读、论证完整、表达自然的中文文章**。沿用高保真浓缩：删去重复表达，不删掉观点成立所依赖的证据。

## 1. 默认成稿结构

1. **原始标题**：逐字保留。
2. **来源**：在标题下标注一次；没有可靠出处就写“来源未注明”或不写，不猜测。
3. **观点总览表**：放在文章前部，通常使用四列：

   | 核心论点 | 原文依据 / 案例 | 推理关系 | 结论 / 适用边界 |
   |---|---|---|---|

4. **正文**：按原材料的思想推进顺序展开。保留必要的逻辑小标题，但不强制套“文章思想、原始文案整理、正文浓缩、最终落点、金句摘录”等重复标签。
5. **个人感悟**：如果原材料中有用户自己的笔记、评论或复盘，放在文章末尾，并与来源观点区分；没有则不新增。
6. **观点辨析 / 外部核验**：仅在确有绝对化结论、证据不足、科学性疑问或用户要求核验时添加，不要机械地每篇都写。

短材料可以缩短表格或不使用表格；用户明确要求观点分析型表格时，保留表格，但不要让表格代替正文。

## 2. 表格负责导航，正文负责论证

- 一行对应一个独立论点，或一组确实紧密相关的论点。
- 每行写清楚观点依赖什么依据、推理如何成立、结论有什么边界。
- 案例多时分别标出，不把不同人物或不同场景合成一个模糊案例。
- 表格单元格只保留关键词和必要事实，不塞进整段文章。
- 表格提到的核心论据必须能在正文找到对应内容；正文不要逐行重复表格。

## 3. 建立信息台账，再进行浓缩

写作前在内部逐项记录：

- 中心主张和每个独立分论点；
- 每个论点的理由、前提、推理关系和适用边界；
- 重要案例的背景、起因、人物行为、关键对话、回应和结果；
- 数字、时间、金额、比较、类比、反例和转折；
- 原材料的表达视角、情绪力度和有辨识度的表达；
- 用户自己的感想、评论或补充。

允许删掉语气词、口播回环、同义反复、无新增信息的重复案例和无关引流。不得因追求短小而删除独立论点、关键证据、案例特有细节、关键对白、数字、比喻、转折或限制条件。

没有固定字数、段落数和压缩比例。篇幅由信息密度决定：重复的解释可以合并，不同的证据不能只因结论相似就合并。宁可保留必要篇幅，也不要让论证失去支撑。

## 4. 案例必须在正文中展开

案例不能只出现在表格中，也不能被压缩成“某人遇到类似问题”一句话。重要案例至少保留：

- **情境**：人物关系、必要背景和事情起因；
- **行为**：各方做了什么，关键选择是什么；
- **对话**：原材料提供的关键原话，保留立场差异；
- **回应与结果**：对方如何回应，事情如何发展或结束；
- **分析**：这个案例支撑哪个论点，能说明什么、不能证明什么。

简单案例可以用一段自然文字讲清；复杂案例可分成数段。不要机械给每个案例套四个标签，也不要把每个案例写成独立短篇故事。

案例不能虚构。不得添加来源没有提供的天气、表情、动作、心理独白、人物背景、台词或结局；不得把多个案例拼成一个虚构的综合故事。原材料没有交代的内容就保留空缺。

## 5. 正文口吻：直接表达，不做第三方旁白

避免反复使用：
- “作者认为……”
- “原文指出……”
- “讲者通过一个例子说明……”
- “这篇文章主要讲了……”
- “这段内容想表达的是……”

直接陈述观点、事件和推理。来源只需在标题下标注一次；确需区分不同说话人或来源观点时，再在局部注明。

保留原始叙述视角：第一人称经历保留“我”；原文直接对听众说话时可保留“你”；故事按人物和事件叙述；一般观点直接陈述。不要把所有内容机械改成第二人称，也不要全部转成第三人称报告。

保留原文的反问、比喻、对照、语气和情绪力度。不要用额外煽情形容词补情绪，也不要把尖锐观点擅自改成温吞的鸡汤。

## 6. 小标题与视觉节奏

- 小标题表达真实的逻辑层次，不为凑结构而拆分。
- 相近的小标题可以合并；短文不必设置多个小节。
- 长文可以按主要论点分节，但不要每两段就插一个标题。
- 自然段围绕一个完整意思组织，避免一句一段，也避免连续大段文字墙。
- 表格通常不超过四列；正文不塞入超长表格单元格。
- 加粗只标记少量关键判断；引用块用于关键原话或对话，不滥用。
- 最高标题级别为二级；中文正文段首缩进两个全角空格。

## 7. 出稿前检查

- [ ] 原始标题是否完整保留，来源是否只标注一次？
- [ ] 每个独立论点是否在表格或正文中有对应位置？
- [ ] 论点、依据、推理和结论是否真实对应？
- [ ] 每个核心案例是否在正文中讲清，而非只出现在表格？
- [ ] 关键数字、对话、比喻、转折和限制条件是否遗漏？
- [ ] 是否有“作者认为 / 原文指出”等不必要的旁白？
- [ ] 是否保留原始人称、语气和情绪，而非机械统一口吻？
- [ ] 是否过度压缩或重复扩写？
- [ ] 小标题、表格、加粗和段落是否清楚且克制？
- [ ] 是否添加了来源没有的场景、心理、事实或结局？
- [ ] 用户个人感悟是否与来源观点分开并放在末尾？
